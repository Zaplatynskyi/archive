# Портал архіву випускників

Веб-портал для пошуку в архіві випускників **факультету механіки, енергетики
та інформаційних технологій** (та підрозділів-попередників).

- **Backend:** Python + Flask
- **База даних:** SQLite з повнотекстовим пошуком FTS5 (українська токенізація)
- **Дані:** автоматичний імпорт зі 120 Excel-описів архіву (1959–2017),
  ~13 300 унікальних записів, денна та заочна форми навчання

---

## 1. Встановлення

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # Linux/macOS
pip install -r requirements.txt
```

## 2. Імпорт даних у базу

Покладіть теку `Архів випускників` поряд із проєктом (або вкажіть шлях
у `.env` — див. `.env.example`).

### 2a. Витяг зі старих Word-документів (одноразово / за потреби)

Частина випусків (заочна 2018–2025, денна 2021–2025) є лише у форматі Word
(`.doc` / `.docx`) — списки дипломів та додатки до наказів. Скрипт
`ingest_docs.py` перетворює їх на Excel-описи стандартного формату:

```bash
python ingest_docs.py
```

Створює файли `Архів випускників/<рік>/_із_Word/<рік>_word.xlsx`
(і аналогічно у `Заочна форма/`). Для університетських списків дипломів
бере лише спеціальності факультету (перелік — у `FACULTY_SPECIALTIES`
всередині скрипта; за потреби відредагуйте).
Потребує `antiword` (для `.doc`): він уже є в середовищі Git Bash.

### 2b. Побудова бази

```bash
python etl.py
```

Скрипт:
- рекурсивно обходить усі `*.xlsx` у теці архіву;
- розпізнає різні варіанти заголовків описів (понад 30 форматів за 60 років);
- визначає рік випуску з назви теки, форму навчання («денна» / «заочна»);
- класифікує напрям (енергетика, механізація, якість…) та освітній рівень;
- прибирає повтори-«лапки» в датах, дублікати записів;
- **повністю перебудовує** `data/alumni.db` — запускайте повторно після
  оновлення Excel-файлів.

Наприкінці виводиться підсумок (скільки файлів, записів, які роки охоплено).

## 3. Запуск

### Для розробки

```bash
python app.py
```
→ http://127.0.0.1:5000

### Продакшн — Windows (waitress)

```bash
waitress-serve --listen=0.0.0.0:8000 app:app
```

### Продакшн — Linux (gunicorn)

```bash
pip install gunicorn
gunicorn -w 4 -b 127.0.0.1:8000 app:app
```

### HTTPS та публічний доступ

Портал слід ставити **за зворотним проксі** (nginx / Caddy / IIS), який
забезпечує TLS-сертифікат. Приклад nginx:

```nginx
server {
    listen 443 ssl;
    server_name arhiv.example.edu;
    ssl_certificate     /etc/letsencrypt/live/arhiv.example.edu/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/arhiv.example.edu/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Перед публічним запуском задайте `SECRET_KEY` у `.env`.

## Можливості пошуку

- повнотекстовий пошук за ПІБ (префіксний: «ковал» знаходить «Ковальчук»);
- фільтри: рік випуску, діапазон років, форма навчання, напрям, освітній рівень;
- сортування за прізвищем або роком;
- картка випускника: період навчання, № архівної справи, кількість аркушів,
  термін зберігання, примітки, посилання на джерело + список однокурсників;
- сторінка «Про архів» з таблицею охоплення за роками.

## Структура проєкту

```
app.py               Flask-застосунок (маршрути, пошук)
etl.py               імпорт Excel → SQLite
config.py            налаштування (шляхи, назва підрозділу) + .env
templates/           HTML-шаблони (Jinja2)
static/style.css     оформлення
data/alumni.db       база даних (генерується etl.py, не в git)
```

## Обмеження та подальші кроки

- **Заочна 1959–1966**: фотографій архівних описів за ці роки немає
  (можливо, заочна форма навчання на факультеті тоді ще не велась, або
  описи не збереглися/не сфотографовані) — закрити прогалину неможливо без
  нових джерел.
- Денна форма тепер повністю покрита (1959–2026, без прогалин). Усі
  раніше відсутні заочні роки (1968, 1970, 1977, 1989, 1990, 2001, 2005,
  2006, 2008, 2009, 2014–2017) перенесені зі сканів вручну в `*_scan.xlsx`
  у відповідних теках — рекомендується вибірково звірити ці записи з
  оригінальними фото (особливо опис 23/292 за 2001 рік — фото дуже
  вицвіле) і за потреби виправити.
- Скани сторінок (~1500 фото, 8.2 ГБ) як зображення до порталу не
  підключені — лише текстові дані з них.
- Портал працює **лише на читання**; виправлення даних — у первинних
  Excel-файлах із подальшим повторним імпортом (`python etl.py`).
- Можливі неточності написання прізвищ і дат, успадковані з первинних
  описів і рукописних журналів видачі дипломів (2019–2020, денна форма).
